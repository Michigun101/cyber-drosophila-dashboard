# CYBER-DROSOPHILA

Киберпанк-панель с 3D-моделью мухи-дрозофилы. Ползунки задают частоту рецепторов, а свечение органов и импульсы по нейронным путям меняются в реальном времени. Модель «предсказывает» ряд данных: погоду в Ухте или курс USD/RUB.

**Демо:** https://michigun101.github.io/cyber-drosophila-dashboard/

## Возможности

- Анатомическая 3D-модель дрозофилы. В ней есть:
  - фасеточные глаза: около 790 омматидиев на глаз и псевдозрачок;
  - перистые усики;
  - хоботок с лабеллумом;
  - полосатое брюшко;
  - крылья с жилками L1–L6 и интерференционной окраской;
  - членистые ноги с коготками;
  - щетинки на голове, груди и брюшке.

  Муху можно вращать мышью вокруг вертикальной оси.
- Ползунки зажигают нейронные пути внутри мухи «на просвет». Это:
  - зрительные доли;
  - антеннальные доли;
  - грибовидные тела;
  - подглоточный ганглий;
  - нервы ног.

  По путям бегут импульсы. При сильном сигнале MN9 муха выдвигает хоботок.
- Три рецептора: зрение, усики Or56a, гигрорецепторы. Частота каждого задаётся от 0 до 200 Гц.
- Два режима данных: погода в Ухте (2 дня факта и 4 дня прогноза) и курс USD/RUB (30 дней, последние 10 дней — бэктест).
- Кнопка симуляции считает прогноз, точность, долю верных направлений и среднюю ошибку (MAE) и выводит вердикт.
- Нейропроекция мозга по данным FlyWire: 15 577 нейронов в реальных координатах и 548 нейронов модели на своих местах. Группы светятся с частотой из ползунков. Есть виды спереди, сверху и сбоку, растр спайков, импульс 200 Гц и снимок PNG.

## Источники данных

- Погода: [Open-Meteo](https://open-meteo.com), ключ API не нужен.
- Курс USD/RUB: [fawazahmed0/currency-api](https://github.com/fawazahmed0/exchange-api) через jsDelivr.
- Нейроны: таблица аннотаций [FlyWire](https://flywire.ai) (Dorkenwald et al., Schlegel et al., Nature 2024).

Данные обновляются каждые 5 минут, кеш живёт 10 минут.

## Запуск локально

Проще всего открыть `index.html` в браузере. Или поднять локальный сервер:

```bash
python3 -m http.server 8000
```

и открыть http://localhost:8000. Нужен интернет: библиотеки и данные загружаются с CDN.

## Технологии

Без сборки: страница `index.html`, 3D-муха `js/fly3d.js`, проекция мозга `js/neuro-projection.js`, данные FlyWire `data/flywire-brain.js`. Tailwind CSS (CDN), Chart.js 4.5.1, Three.js 0.186.1, шрифт Orbitron.

## Ограничения

Модель прогноза демонстрационная: линейная экстраполяция с шумом. Это не финансовая и не метеорологическая рекомендация, и вердикт «рост/спад» не является торговым сигналом.
