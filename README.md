# CYBER-DROSOPHILA

Киберпанк-панель с 3D-моделью мухи-дрозофилы. Ползунки задают частоту рецепторов, а свечение органов и импульсы по нейронным путям меняются в реальном времени. Модель «предсказывает» ряд данных: погоду в Ухте или курс USD/RUB.

**Демо:** https://michigun101.github.io/cyber-drosophila-dashboard/

## Возможности

- 3D-муха, которую можно вращать мышью вокруг вертикальной оси. Свечение глаз, усиков, мозга и хоботка (MN9) зависит от ползунков.
- Три рецептора: зрение, усики Or56a, гигрорецепторы. Частота каждого задаётся от 0 до 200 Гц.
- Два режима данных: погода в Ухте (2 дня факта и 4 дня прогноза) и курс USD/RUB (30 дней, последние 10 дней — бэктест).
- Кнопка симуляции считает прогноз, точность, долю верных направлений и среднюю ошибку (MAE) и выводит вердикт.

## Источники данных

- Погода: [Open-Meteo](https://open-meteo.com), ключ API не нужен.
- Курс USD/RUB: [fawazahmed0/currency-api](https://github.com/fawazahmed0/exchange-api) через jsDelivr.

Данные обновляются каждые 5 минут, кеш живёт 10 минут.

## Запуск локально

Проще всего открыть `index.html` в браузере. Или поднять локальный сервер:

```bash
python3 -m http.server 8000
```

и открыть http://localhost:8000. Нужен интернет: библиотеки и данные загружаются с CDN.

## Технологии

Один HTML-файл без сборки: Tailwind CSS (CDN), Chart.js 4.5.1, Three.js 0.186.1, шрифт Orbitron.

## Ограничения

Модель прогноза демонстрационная: линейная экстраполяция с шумом. Это не финансовая и не метеорологическая рекомендация, и вердикт «рост/спад» не является торговым сигналом.
